# 🧪 MATLAB Aplicado a quimiometria

**Computação científica • Matemática • Quimiometria**

Este repositório reúne meus estudos, exercícios e códigos desenvolvidos durante a disciplina introdutória de MATLAB. O objetivo é documentar minha evolução em programação científica e construir uma base computacional para aplicações futurasa.

## 🎯 Objetivos

- Desenvolver familiaridade com o ambiente MATLAB.
- Aprender a construir, executar e organizar scripts.
- Aplicar conceitos matemáticos por meio da programação.
- Desenvolver habilidades de resolução de problemas científicos.
- Construir uma base para estudos futuros em análise de dados e quimiometria.
